## Detailed Description (Max 16,000 characters)

### Overview
Transform your web browsing into a powerful language learning experience! Translation & Learning Assistant is the ultimate Chrome extension for translating web pages with AI-powered intelligence.

### ✨ Key Features

**🎯 Smart Auto Paragraph Detection** (NEW!)
- Automatically detects paragraphs on any webpage
- Filters out navigation, ads, and irrelevant content
- Three detection modes: Aggressive, Balanced, Conservative
- Inline translation overlays with smooth animations
- Toggle between original and translated text with one click
- Keyboard shortcut: Alt+T to toggle all paragraphs

**📝 Text Selection Translation**
- Select any text on web pages or PDFs
- Instant translation with beautiful tooltip UI
- Right-click context menu support
- Preserves formatting and context

**💬 Interactive Learning**
- Ask follow-up questions about translations
- Chat interface for deeper understanding
- Streaming responses for real-time feedback
- Learn grammar, usage, and cultural context

**🤖 Multi-AI Provider Support**
- **Claude** (Anthropic) - Advanced language understanding
- **GPT-4** (OpenAI) - Powerful and versatile
- **Gemini** (Google) - Fast and efficient
- Switch providers anytime in settings
- Bring your own API key for full control

**📚 Translation History**
- Automatic history tracking with source URLs
- Search and browse past translations
- Export your learning progress
- Never lose valuable translations

**☁️ Cross-Device Sync** (Optional)
- Firebase-powered synchronization
- Access translations on all your devices
- Google Sign-In authentication
- Privacy-focused: sync only what you want

**📄 PDF Support**
- Translate text in PDF documents
- Page number tracking
- Works with Chrome's built-in PDF viewer

**⚡ Performance Optimized**
- Smart caching reduces API calls by 60%+
- Batch translation for multiple paragraphs
- Only translates visible content first
- Lightning-fast with minimal overhead

### 🎨 Beautiful & Modern UI

### 🚀 Getting Started

1. **Install the Extension**
2. **Get an API Key**
   - Choose your AI provider (Claude/OpenAI/Gemini)
   - Get API key from their website
3. **Configure Settings**
   - Enter your API key in Options
   - Select target language (Korean, English, Japanese, etc.)
   - Enable auto paragraph detection if desired
4. **Start Translating!**
   - Select text for quick translation
   - Enable auto-detect for full-page translation
   - Use Alt+T to toggle translated paragraphs

## Permissions Justification

**Required Permissions:**
- **activeTab**: To access selected text on current page
- **storage**: To save settings, history, and cache
- **sidePanel**: To display translation side panel
- **scripting**: To inject content scripts for translation overlays
- **contextMenus**: To add right-click translation option
- **identity**: For optional Google Sign-In (Firebase sync)

**Host Permissions:**
- **<all_urls>**: Required to translate text on any website (user's choice)

**Why We Need These:**
All permissions are essential for core functionality. We use minimal permissions and respect your privacy.
